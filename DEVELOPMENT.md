# Development

Keep this project a small offline ledger validator and report generator. Preserve
the existing schema and report modes, explicit review/milestone boundaries and
author-supplied statuses. Do not infer truth, deaths or evidence quality.

Read README.md and TESTING.md before changes. Use synthetic fixtures, a feature
branch and a protected pull request. CI and CodeQL must pass before a maintainer
merges; never weaken coverage, checks or review requirements. Release the exact
reviewed commit with matching package version, changelog and tag-build artifacts.
